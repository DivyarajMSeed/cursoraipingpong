# 3D Ping Pong Game (iOS, SceneKit)

## Setup Instructions

1. **Create a new Xcode Project:**
   - Open Xcode on your Mac.
   - Select "App" under iOS.
   - Product Name: `PingPong3D`
   - Interface: `Storyboard` or `SwiftUI` (either is fine; code will use UIKit overlay for score/lives).
   - Language: `Swift`
   - Game Technology: `SceneKit`

2. **Replace/Add Files:**
   - Replace the default `GameViewController.swift` and `GameScene.swift` with the provided versions.
   - Add any additional files as instructed (e.g., for UI overlay).

3. **Run the Project:**
   - Build and run on a simulator or device.

4. **Controls:**
   - Swipe left/right to move your paddle.

5. **Features:**
   - Green table, red player paddle, white ball, side walls, AI opponent, scoring, lives, physics, camera effects, and sound.

---

Copy the provided Swift files into your Xcode project as described above.
